十、给非金融人的 5 个关键结论

  1. Anthropic 已经"营收反超" OpenAI。$44B vs $25B，但估值（$380B 已完成）只有 OpenAI 的 45%——这是市场反应"滞后"的窗口，正是 $50B / $900B 新一轮要 catch up 的核心。
  2. $44B ARR ≈ AMD 全年营收的 1.27 倍（AMD 2025 = $34.6B），≈ Oracle FY25 的 77%。一家 5000 人的 AI 初创，年化营收已超过半导体行业老 4。
  3. 5 个月翻 5 倍 = SaaS 史无前例。2025-12 ARR $9B → 2026-05 $44B；平均每天净增 $96M ARR——每天产生一个独角兽公司全年的收入。
  4. PS 已压到 8.6× = 成熟 SaaS 倍数。这意味着已完成估值（$380B）已经按"Anthropic 是 Salesforce 类成熟公司"定价；$900B 在谈估值才把"高速增长溢价"重新加回。
  5. 核心驱动力 = Claude Code + Sonnet 4.x 模型。开发者市场对 Claude Code 的渗透是过去 6 个月最大变量；1000+ 企业客户 >$1M/年（数月翻倍）说明 API 商业化已破竹。

十一、值得继续追踪的 5 个关键指标

  1. $900B 一轮是否落地。5 月底前的董事会决定，决定估值是否"reset"。
  2. Anthropic 季度 ARR 演变。从 $44B 起跑，能否维持月 +$5B 以上增速。
  3. 毛利率从 70% 继续向上 / 横盘？推理成本下降速度直接决定盈利时间表。
  4. Claude 4.x → 5.0 模型代际。一旦落后 OpenAI / Google 半代以上，PS 溢价（即使 8.6× 都可能修正）会快速消失。
  5. Anthropic IPO 时间线。TechCrunch 提到最早 2026-10。一旦上市，PS 会被 Salesforce / Adobe / ServiceNow 等成熟标的"重新校准"。
