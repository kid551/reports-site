本表是一份「品种 → 矛盾」的横向对照速查。每个品种只抓三件事：①靠什么逻辑定价（金融/商品/政策），②卡在产业链哪个位置（上游成本、下游需求），③当前最值得盯的那一对矛盾（通常是"供给的某种刚性/扩张" 撞上 "需求的某种弹性/萎缩"，再叠加一项成本或政策变量）。读法：先看矛盾点一栏，那是交易与研究的发力处。

一、上海期货交易所

SHFE

定位：金属定价主战场。沪铜、沪铝、沪金在亚洲乃至全球都有重要影响力，是"金融属性 + 工业属性"叠加最典型的市场。

贵金属

品种产业逻辑上下游关系供需 / 成本矛盾点
黄金AU 金融属性 ≫ 商品属性。本质是"无息抗通胀货币"，对标实际利率与信用。 金矿/再生金 → 冶炼 → 首饰、工业、央行储备、投资。 实际利率 vs 避险：美债实际利率↑→金价承压；地缘风险、央行购金、美元信用走弱→支撑。矿产供给刚性，基本面退居次要，美联储货币政策主导定价。
白银AG 半金融半工业，弹性大于黄金。涨跟黄金、跌看工业。 银矿(多为铜铅锌伴生) → 冶炼 → 光伏银浆、电子、首饰、投资。 伴生供给刚性 vs 光伏需求爆发：银矿难独立增产，而光伏银浆消耗逐年攀升；金融端跟随黄金，金银比是核心观测，库存持续去化时弹性最大。

有色金属

品种产业逻辑上下游关系供需 / 成本矛盾点
铜CU "铜博士"，经济晴雨表。强金融 + 强工业双属性。 铜精矿(智利/秘鲁) → 冶炼(TC/RC加工费) → 电力、家电、新能源、建筑。 矿端增速放缓 vs 新能源需求增量：老矿品位下降、资本开支不足，新增供给乏力；电网/光伏/EV 带来长期增量。TC/RC 加工费反映矿紧张程度，叠加宏观流动性定价。
铝AL 高耗能金属，受 4500 万吨产能天花板与电力成本双重约束。 铝土矿 → 氧化铝 → 电解铝(耗电) → 汽车、建筑、光伏。 产能红线下供给刚性 vs 轻量化/光伏需求：国内产能见顶，需求仍有增量。电力成本是核心成本变量，云南丰枯水期电价波动直接引发限产/复产预期。
氧化铝AO 电解铝的直接原料，产能弹性大、易过剩，价格波动剧烈。 铝土矿(几内亚/国产) → 氧化铝 → 电解铝。 铝土矿扰动 vs 氧化铝产能过剩：几内亚矿端政策风险是上行催化，但自身产能充裕，一旦矿端缓和价格快速回落。成本端 = 铝土矿 + 烧碱 + 能源。
铸造铝合金AD
2025-06 新上市 · 首个再生品种
 再生铝，循环经济首个期货品种，绿色低碳叙事。 废铝回收 → 再生铝合金锭 → 汽车压铸件(一体化压铸)。 废铝回收体系不成熟 vs 压铸需求增长：废铝供给分散、回收率受政策与价差影响；新能源车一体化压铸打开需求。核心观测 废铝-精铝价差及与电解铝(AD-AL)价差。
锌ZN 镀锌为主，地产基建后周期金属。 锌矿 → 冶炼(加工费) → 镀锌板、压铸合金、地产基建。 矿端加工费 vs 地产基建需求走弱：矿紧时冶炼加工费(TC)下行压制供给；下游受地产拖累。库存周期与升贴水是节奏指标。
铅PB 蓄电池为主，再生铅占比高，价格波动相对温和。 铅锌矿/再生铅 → 精铅 → 铅酸蓄电池(汽车启停、电动两轮车)。 再生铅供给 vs 锂电替代的长期需求萎缩：原生铅与再生铅竞争压价；锂电对铅酸的替代构成长期利空，短期看电动两轮车存量换电与消费旺季。
镍NI 不锈钢 + 新能源(三元电池)双驱动，结构复杂。 镍矿(印尼/菲律宾) → 镍铁/硫酸镍/电解纯镍 → 不锈钢、三元前驱体。 印尼供给大爆发(过剩) vs 不锈钢+电池需求：印尼镍铁/MHP 产能扩张压制全球价格；纯镍与镍铁存在结构性矛盾。印尼资源政策是最大变量。
锡SN 小金属，焊料(电子)为主，供给高度集中、弹性大。 锡矿(缅甸佤邦/印尼) → 精锡 → 电子焊料、锡化工、镀锡。 缅甸供给扰动+资源枯竭 vs 半导体需求：佤邦停复产消息可瞬间改变供需平衡；矿端枯竭使供给刚性强。需求随半导体/消费电子周期波动。

黑色金属（成材）

品种产业逻辑上下游关系供需 / 成本矛盾点
螺纹钢RB 建筑钢材，地产+基建核心晴雨表，黑色系定价锚。 铁矿+焦炭 → 钢厂 → 地产、基建工程。 地产需求萎缩 vs 粗钢产量调控：需求端长期下台阶；供给端靠政策"压减粗钢"托底。核心是 钢厂吨钢利润——利润扩→复产增产→反噬利润。
热轧卷板HC 工业用钢，对应制造业/汽车/家电/出口，比螺纹更"工业"。 铁矿+焦炭 → 钢厂 → 汽车、家电、机械、出口。 制造业/出口需求 vs 产量：需求比螺纹有韧性。卷螺差(HC-RB)是判断"制造业 vs 地产"强弱的经典指标。
不锈钢SS 镍铬铁合金钢，耐腐蚀，兼具消费与工业属性。 镍铁+铬铁+废钢 → 不锈钢 → 家电、厨具、工业管材。 镍铁成本+过剩 vs 需求：成本驱动极强(印尼镍铁价格直接传导)；自身产能过剩使利润长期被压缩。
线材WR 建筑/拉丝用钢，与螺纹高度同源，流动性低、近休眠。 同螺纹链条。 矛盾与螺纹一致，但流动性极差，多作产业参考而非主力交易。

能源化工

品种产业逻辑上下游关系供需 / 成本矛盾点
燃料油FU 高硫燃油，船燃+炼厂原料，紧跟原油。 原油 → 燃料油 → 船舶燃料、炼厂调和/二次加工。 IMO 限硫后船用萎缩 vs 炼厂/发电需求：高硫油船用场景受限；与原油的裂解价差、与低硫油 LU 的高低硫价差是核心。
沥青BU 道路基建材料，原油下游，季节性(Q3旺季)明显。 原油/稀释沥青(委内瑞拉) → 沥青 → 公路、市政基建。 基建资金(财政/专项债) vs 炼厂开工：需求看基建强度与天气；成本看原油与委油供应。利润差驱动炼厂排产。
天然橡胶RU 轮胎为主，兼具农产品属性(割胶有季节)。 橡胶树(东南亚/海南云南) → 天然橡胶 → 轮胎、工业制品。 种植/割胶刚性 vs 轮胎需求：树龄周期长、停割期供给收缩；需求看汽车与重卡。产区天气、原料价是高频扰动。
丁二烯橡胶BR 合成橡胶(顺丁)，轮胎用，石油化工下游。 原油 → 丁二烯 → 顺丁橡胶 → 轮胎。 丁二烯成本 vs 合成-天然替代：上游丁二烯价格波动大，决定成本；与天然橡胶比价决定轮胎厂的配方替代。
纸浆SP 造纸原料(漂针浆)，进口依赖度极高。 木材 → 木浆(进口为主) → 文化纸、生活用纸。 海外浆厂投产周期 vs 国内纸厂需求：供给由海外大浆厂检修/投产主导；成本受汇率+海运+进口报价影响，国内需求偏刚性。

二、上海国际能源交易中心

INE

定位：上期所子公司，承担国际化品种、对境外交易者开放，是中国争夺国际定价权的核心平台。

国际化商品期货

品种产业逻辑上下游关系供需 / 成本矛盾点
原油SC "大宗之母"，能源定价基准，供需+金融+地缘三重属性。 上游油田 → 原油 → 炼厂(成品油、化工全产业链起点)。 OPEC+减产 vs 美页岩增产，叠加地缘溢价(中东/俄乌) vs 全球需求(经济周期)。SC 还多一层内外价差与中质含硫定价。
20号胶NR 轮胎用标准胶，国际化合约，更贴近轮胎厂实际原料。 同天然橡胶，但对应标胶现货。 矛盾同 RU(产区天气、割胶季、轮胎需求)；核心额外看 RU-NR 价差(全乳胶 vs 标胶)。
低硫燃料油LU IMO2020 后的合规船用燃料。 原油 → 低硫燃油 → 国际航运船燃。 船用合规需求 vs 炼厂供给：核心是 LU-FU 高低硫价差，反映合规油溢价与航运景气。
国际铜BC 保税交割、人民币计价的国际铜，对标 LME。 同铜产业链，定价在保税环节。 内外盘价差(沪伦比) vs 保税区供需：是进口盈亏与跨市套利的工具，矛盾本质同 CU 但多一层汇率与关税。

航运指数（独立类别）

品种产业逻辑上下游关系供需 / 成本矛盾点
集运指数(欧线)EC 全球首个集装箱航运指数期货，服务外贸企业运价套保。 出口货量 → 集装箱运力(船公司) → 中欧航线运价。 运力供给 vs 外贸出口需求：船舶交付节奏、红海绕行好望角(等效抽走运力)、联盟挺价 vs 货量旺淡季。地缘事件使其弹性极大，是商品中最"事件驱动"的品种之一。

三、大连商品交易所

DCE

定位：农产品与能化双轮驱动。是铁矿石、豆粕产业链定价权的主战场。

农产品（含养殖）

品种产业逻辑上下游关系供需 / 成本矛盾点
黄大豆1号A 国产非转基因大豆，主要用于食品/豆制品。 国产大豆(东北) → 食品、蛋白、豆制品。 国产种植面积(政策补贴) vs 进口替代：受种植补贴与收储政策影响，食用需求平稳，价格相对独立于国际盘。
黄大豆2号B 进口转基因大豆，主要用于压榨。 进口大豆(美/巴) → 压榨 → 豆粕+豆油。 进口成本 vs 压榨需求：紧跟 CBOT 大豆 + 汇率 + 升贴水，是进口大豆到港成本的定价工具。
豆粕M 最核心的蛋白饲料原料，农产品主力合约之一。 大豆 → 压榨 → 豆粕 → 饲料(生猪/家禽)。 进口成本+南美天气 vs 养殖需求：上游看南美/北美产量与中美贸易，成本端是 CBOT；下游看生猪存栏。油粕比决定压榨利润在油与粕间的分配。
豆油Y 主流食用油，大豆压榨副产品。 大豆 → 压榨 → 豆油 → 食用油、餐饮。 油粕比争产出 vs 三大油脂替代：与豆粕争压榨产出；与棕榈油、菜油强联动(豆棕价差决定消费替代)。
棕榈油P 全球产量最大食用油，进口为主，食用+生物柴油双需求。 油棕(马/印) → 棕榈油(进口) → 食用、生物柴油。 马印产量/库存 vs 生柴政策：供给看 MPOB 库存与天气(厄尔尼诺减产)；需求受印尼 B35/B40 生柴掺混政策强驱动，是油脂板块的领涨/领跌者。
玉米C 最大饲料粮+深加工原料，国内供需主导。 玉米种植 → 饲料、淀粉、燃料乙醇。 种植面积+进口政策 vs 饲料+深加工需求：供给看播种与进口配额；需求看生猪存栏。小麦/进口谷物替代是上沿压制。
玉米淀粉CS 玉米深加工，工业+食品用。 玉米 → 淀粉 → 食品、造纸、糖浆。 玉米成本 vs 加工利润：价格 = 玉米成本 + 加工费，核心看 淀粉-玉米价差反映的深加工开工与下游需求。
粳米RR 口粮，政策性强，流动性极低。 稻谷 → 粳米 → 口粮消费。 受最低收购价等政策托底，市场化波动小，交投清淡。
鸡蛋JD 少数贴近现货的"养殖周期"品种，季节性强。 蛋鸡养殖(饲料) → 鸡蛋 → 居民消费。 在产蛋鸡存栏(补栏/淘汰) vs 季节消费：供给看存栏与开产周期；需求看中秋等旺季。饲料(玉米豆粕)成本构成底部。
生猪LH "猪周期"核心，CPI 权重大，养殖产业晴雨表。 饲料(玉米+豆粕) → 生猪养殖 → 猪肉消费。 能繁母猪存栏(产能去化) vs 消费：产能领先猪价约 10 个月，是周期主矛盾；成本端饲料；压栏/二次育肥放大短期波动。

黑色原料

品种产业逻辑上下游关系供需 / 成本矛盾点
焦煤JM 炼焦核心原料，进口(蒙煤/澳煤)+国产。 煤矿 → 焦煤 → 焦炭。 蒙煤进口+国内安监 vs 焦钢需求：供给受通关量与煤矿安全检查影响弹性大；需求由焦炭/钢厂铁水决定，是黑色系成本的最上游。
焦炭J 钢铁冶炼还原剂，介于焦煤与钢之间。 焦煤 → 焦化厂 → 钢厂。 焦煤成本+环保限产 vs 钢厂需求：核心是 焦化利润——焦企议价能力弱，常被上下游两头挤压。"提涨/提降"博弈节奏感强。
铁矿石I 钢铁第一大原料，进口依赖>80%，黑色系定价权争夺焦点。 铁矿(澳/巴四大矿山) → 钢厂 → 钢材。 四大矿寡头供给 vs 钢厂铁水产量：供给由 VALE/力拓/必和必拓/FMG 发运主导；需求高度绑定地产与粗钢压减政策。"反内卷"控产与定价权博弈是长期主题。

能源化工（烯烃链）

品种产业逻辑上下游关系供需 / 成本矛盾点
液化石油气PG 燃料+化工原料(PDH)双重身份，季节性强。 油气田/炼厂 → LPG → 民用燃烧 / 丙烷脱氢(PDH)。 进口成本(CP/FEI)+冬季燃烧 vs PDH化工需求：冬季燃烧旺季与 PDH 利润共同争夺货源；价格紧跟原油与丙烷国际报价。
聚乙烯L 第一大通用塑料(PE)，农膜/包装为主。 原油/煤 → 乙烯 → PE → 农膜、包装。 新增产能投产 vs 包装农膜需求：国内大炼化新装置集中投产带来过剩；油化工 vs 煤化工成本竞争决定成本支撑位。农膜有季节性。
聚氯乙烯V 建材塑料(PVC)，国内电石法为主，地产链。 电石(兰炭+电)/乙烯 → PVC → 管材、型材(地产)。 电石成本(能耗双控) vs 地产需求疲弱：成本端受电石/电价支撑，需求端受地产拖累——典型"成本与需求双弱"格局，长期产能过剩。

总纲：为什么大宗商品天生适合用《矛盾论》来读

"事物发展的根本原因，不是在事物的外部而是在事物的内部，在于事物内部的矛盾性。"
"研究问题，忌带主观性、片面性和表面性。所谓片面性，就是不知道全面地看问题。" ——《矛盾论》

大宗商品的价格，本质上就是供给与需求这一对矛盾在数字上的瞬时投影。它天然满足《矛盾论》的几条核心判断：

普遍性 共性

一切商品都逃不开供需矛盾——这是"价格波动"的共同根据。四条链可以用同一套语言去谈。

特殊性 个性

但每条链、每个品种、每个阶段的矛盾形态都不同。分析的着力点，正在于抓住"这一个"的特殊矛盾，而非停在"供需决定价格"的废话层。

主要矛盾 / 次要矛盾

一条产业链同时存在许多矛盾（成本、产能、库存、政策、天气），其中必有一个在当前阶段起主导——找到它，就找到了定价主线。

矛盾的主要方面 / 次要方面

"供给 vs 需求"两方发展不平衡。哪一方当前占上风，就决定了价格方向：供给过剩主导下跌，还是需求拉动主导上涨。

内因 / 外因

产能、库存、成本结构、产业周期是内因；宏观、政策、天气、地缘是外因。外因必须通过内因起作用——油价涨若无需求承接，只会吃掉加工费。

同一性 / 斗争性 + 转化

上下游既相互依存，又在利润分配上相互争夺；过剩与短缺、成本支撑与崩塌都会在一定条件下向对立面转化——这正是趋势反转的来处。

链条 ①

芳烃—烯烃化工链：被两头挤压的"加工费战争"

原油 SC → PX / 纯苯 BZ / 丙烯 PL → PTA / 苯乙烯 EB / 聚丙烯 PP → 短纤 PF / 瓶片 PR（聚酯终端）

1基本矛盾：成本推动 与 需求拉动 的对立统一

供给侧（成本推动）
原油成本 + 各环节产能。原油是价值起点，产能投放决定供给量，成本要逐环传导。
⚔
需求侧（需求拉动）
终端聚酯——纺服、饮料包装、家纺，及出口订单。需求决定成本能否被顺利传导出去。

这条链足够长：从原油到一件衣服要 5 个以上环节。链长意味着每个环节都有自己的小供需矛盾，彼此通过"加工费/价差"传染。整条链总利润（终端售价−原油成本）是固定的蛋糕，各环节都在抢。

2主要矛盾与主要方面：供给过剩已压倒需求

当前主要矛盾

民营大炼化产能集中投放带来的全链条过剩，与终端需求增长乏力之间的矛盾。症状是加工费被持续压缩、长期贴近现金成本线。

4内因与外因：油价上涨为何常"利空"中游

内因（根据）
各环节产能投放、装置一体化程度、库存周期。决定固定总利润如何在链条上分配。
外因（条件）
原油价格、汇率、出口订单、调油逻辑、宏观纺服消费。
外因必须通过内因起作用——终端需求疲弱（内因：供给过剩、议价权弱）时，原油上涨（外因）无法向终端传导，只会从中游加工费里"吃"掉一块。这就是"成本涨、中游反更难受"的常识。

5同一性与斗争性：固定蛋糕的"两头挤中间"

同一性
PX 离不开 PTA 买盘，聚酯离不开 PTA 供给。终端不开工，上游卖给谁？
⇌
斗争性
谁有产能话语权、谁有一体化成本优势，谁就在价差里多分。当前上游资源 + 终端品牌两头强，中间 PTA/聚酯加工被挤压。

→

仍处产能消化期，主要方面在供给。发力点是每个环节的加工费/价差。加工费的趋势性修复依赖供给侧出清与"反内卷"，而非押注油价或终端。

2主要矛盾与主要方面：需求趋势性下台阶

当前主要矛盾

地产长周期下行带来的用钢需求收缩，与「压减粗钢」行政控产之间的矛盾。主要方面在需求侧——地产用钢趋势性下台阶，决定中枢长期下移。

需求趋势走弱时，供给端出现一只"政策的手"——压减粗钢去对冲。于是黑色成了"需求向下、政策托底"的对冲博弈，钢厂利润是胜负手。

3矛盾的特殊性：每个环节话语权天差地别

环节该环节主要方面特殊矛盾点

焦煤 JM供给（政策+进口）受煤矿安监、蒙煤/澳煤通关影响，是黑色成本最上游。
焦炭 J利润（被两头挤）夹在焦煤与钢厂间，议价能力最弱、斗争性最激烈，"提涨/提降"博弈强。
螺纹 RB需求（地产）地产+基建晴雨表，黑色定价锚，需求下行最直接承受者。
热卷 HC需求（制造业）制造业/出口更有韧性；卷螺差反映"制造业 vs 地产"不平衡。
硅铁/锰硅成本（电/锰矿）炼钢辅料，硅铁看电价+双控，锰硅看进口锰矿，需求随粗钢被动波动。

4内因与外因：政策如何通过钢厂利润起作用

内因（根据）
钢厂利润、铁水产量、库存周期、产能结构。一切生产决策的真实出发点。
外因（条件）
地产政策、基建财政、粗钢压减、出口、矿山发运。
"压减粗钢"不是直接命令价格，而是通过改变钢厂生产决策（内因）起作用：行政限产→供给收缩→若强于需求下滑→钢价与利润回升。这是黑色特有的"政策对冲需求"逻辑。

5同一性与斗争性：钢厂利润 与 矿价 的负反馈

同一性
矿-焦-钢一荣俱荣：钢厂减产，铁矿焦炭需求同步萎缩。
⇌
斗争性（经典负反馈）
钢厂利润好→敢买高价矿→利润向矿端转移；钢厂亏损→打压采购→矿焦承压。"钢厂利润 vs 矿价"是最著名的拉锯。

6矛盾的转化：什么条件下黑色逆势走强

需求趋势走弱条件：地产企稳 / 基建超预期
→
主要方面阶段性回到需求拉动
供给被动跟随条件：粗钢压减力度强于需求下滑
→
供给侧主导，钢价逆势上行
矿端寡头供给主导条件：「基石计划」集采见效
→
矿价主导削弱，利润回流钢厂
时点判断 · 2026

需求趋势走弱是不变的主要矛盾，但"反内卷"控产构成对冲，钢厂吨钢利润是最关键高频观测。卷螺差判断需求结构，铁矿/焦炭基差判断原料强弱。

链条 ③

新能源链：一场"主要矛盾向对立面转化"的教科书

工业硅 SI → 多晶硅 PS（光伏）｜ 锂矿 → 碳酸锂 LC（电池）｜ 废铝 → 铸造铝合金 AD（再生）

1基本矛盾：长期成长性需求 与 资本逐利的无序扩张

供给侧
资本逐利驱动的产能投放。高价高利润→疯狂扩产→供给迅速膨胀。
⚔

这条链基本矛盾多一层戏剧性：需求的长期确定性，恰恰诱发了供给的短期无序。所有人都相信光伏/电池是未来，于是所有人都来扩产——确定的需求，制造了过剩的供给。

品种该品种主要方面特殊矛盾点

5同一性与斗争性：成本与需求互为镜像

⇌

第 三 部 分 · 压 力 测 试

主要矛盾的反向估值压力测试：当前价格隐含了什么

前两部分讲的是矛盾"是什么"——定性。这一部分借「反向估值审计」的骨架把它量化：不预测未来，而是倒推当前价格已经把市场对供需的什么假设定价进去，再用 Tushare 真实期货数据把它拉回历史样本对账，看落在什么分位、需要多大"反常"才能维持，以及假设落空时下行到哪。

商品没有 PE，所以把"估值锚"换成每条链最能代表主要矛盾的可核查价格/价差/利润变量。

"这个价位已经定价进去了什么样的供需？历史让这种供需出现过多频繁？假设落空，跌/涨到哪？"

方法三步（借自 reverse-valuation-audit）：① 隐含假设（当前价隐含的供需）→ ② 现实性检验（真实历史分位）→ ③ 下行/修复测算（回归中位与极值，对应"麦当劳铁律：必算下行"）。

数据与可复用：所有分位与下行数字由 Python 脚本对 Tushare 期货主力连续结算价真实计算，正文数字 = 脚本输出（脚本附本部分末尾）。分位条颜色：左绿（历史低位/便宜）→ 右红（历史高位/贵）。
诚实声明（据 reverse-valuation-audit 规则 7「信息不足明确停止」）：① Tushare fut_daily 单次上限 2000 行，故 RB/I/TA/P/油粕比等窗口为 2018-02 至今约 8 年（非全历史）；② PTA「加工费」因 PX 期货 2023-09 才上市，可比样本仅 2.5 年且全程处于过剩期，分位参考性弱，本节明确标注该项信息不足、不强行给跨周期频次；③ 钢厂毛利、PTA 加工费为盘面代理（未扣全部加工成本），用于看分位趋势而非绝对盈亏；④ 分位 = 结算价在样本中的位置分位。

附：计算脚本（Tushare 真实数据，可复用）

所有分位与下行数字均由下方脚本对 Tushare 期货主力连续结算价计算，正文数字 = 脚本 print 输出。改 CODES 与窗口可本地重跑。
import urllib.request, json, os

TOKEN = os.environ["TUSHARE_TOKEN"]
def ts_call(api, **p):
    payload = {"api_name": api, "token": TOKEN, "params": p}
    req = urllib.request.Request("https://api.tushare.pro",
        data=json.dumps(payload).encode(), headers={"Content-Type":"application/json"})
    r = json.loads(urllib.request.urlopen(req, timeout=60).read())
    return [dict(zip(r["data"]["fields"], it)) for it in r["data"]["items"]]

def series(code):                       # 主力连续结算价(缺失回退收盘)
    rows = ts_call("fut_daily", ts_code=code, start_date="20140101",
                   end_date="20260524", fields="trade_date,close,settle")
    rec = [(x["trade_date"], float(x["settle"] or x["close"]))
           for x in rows if (x["settle"] or x["close"])]
    return sorted(rec)

def pct_stats(vals, cur):               # 分位 + 五数概括
    v = sorted(vals); n = len(v)
    q = lambda p: (lambda i: v[int(i)] + (v[min(int(i)+1,n-1)]-v[int(i)])*(i-int(i)))(p*(n-1))
    rank = sum(1 for x in v if x <= cur)/n*100
    return dict(n=n, cur=round(cur,2), p50=round(q(.5),2),
                lo=round(v[0],2), hi=round(v[-1],2), pctile=round(rank,1))

CODES = {"RB":"RB.SHF","HC":"HC.SHF","I":"I.DCE","J":"J.DCE","Y":"Y.DCE","M":"M.DCE",
         "P":"P.DCE","LH":"LH.DCE","TA":"TA.ZCE","PX":"PX.ZCE",
         "LC":"LC.GFE","PS":"PS.GFE","SI":"SI.GFE"}
S = {k: series(c) for k, c in CODES.items()}

# 单品种分位
for k in ["LC","PS","SI","I","RB","P","LH","TA"]:
    vals = [px for _, px in S[k]]
    print(k, pct_stats(vals, vals[-1]))

# 派生：对齐交易日做价差/比值（示例：油粕比、钢厂毛利代理、卷螺差）
def align(*ks):
    common = sorted(set.intersection(*[set(d for d,_ in S[k]) for k in ks]))
    return common, {k: [dict(S[k])[d] for d in common] for k in ks}

_, r = align("Y","M");  ratio = [y/m for y,m in zip(r["Y"],r["M"])]
print("油粕比", pct_stats(ratio, ratio[-1]))
_, r = align("RB","I","J"); gm = [rb-1.6*i-0.5*j for rb,i,j in zip(r["RB"],r["I"],r["J"])]
print("钢厂毛利代理", pct_stats(gm, gm[-1]))      # 未扣其他加工费约1000-1200
_, r = align("HC","RB"); sp = [h-rb for h,rb in zip(r["HC"],r["RB"])]
print("卷螺差", pct_stats(sp, sp[-1]))
