4反向估值审计：当前价格隐含了什么

工业富联 PE TTM = 31.98×（Tushare 2026-05-21），市值约 1.30 万亿元。

"这个价位已经定价进去了什么样的未来？历史让这种未来发生过几次？"

v3 关键变化：PE 锚从 v2 的"经验估算（27/34.5/49.5×）"更新为 Tushare 真实数据（31.07/38.74/49.28×）；基期盈利从年报静态 352.86 亿更新为 TTM 406.49 亿；CAGR 现实性检验从"信息不足跳过"更新为 Tushare income 拉取的真实 5 年 CAGR 分布。

通常的 DCF 是"给出增速假设，算出目标价"；Reverse DCF 反过来：固定当前市值，用二分法求解"市场已经定价进去的增速 g_explicit"，再问这个增速在历史上出现过几次。
把 PE 翻译成时间语言：当前市值 / TTM 净利润 = 若盈利不增长，需要多少年累计利润才能等于投入的市值。PE 31.98× 即 31.98 年回本。
DCF 模型中，显性预测期结束后假设公司以固定增速永续经营。本报告取 3%，对齐中国长期名义 GDP 增长中枢。

import math

def percentile(lst, pct):
    """线性插值分位数"""
    sorted_lst = sorted(lst)
    n = len(sorted_lst)
    if n == 0: return None
    idx = pct / 100 * (n - 1)
    lo = int(idx)
    hi = min(lo + 1, n - 1)
    return sorted_lst[lo] + (sorted_lst[hi] - sorted_lst[lo]) * (idx - lo)

    pv = sum(FCF0 * (1+g)**t / (1+r)**t for t in range(1, T+1))
    FCF_T = FCF0 * (1+g)**T
    TV = FCF_T * (1+g_term) / (r - g_term)

5反方观点与风险清单

  • 风险 1：毛利率结构性下行。FY2025 毛利率 6.98%，较 FY2023 的 8.06% 下降逾 1 pct，与"AI 升值"叙事矛盾。AI 服务器价格竞争加剧将进一步压缩利润空间。[3]
  • 风险 2：大客户资本支出周期风险。高度依赖超大规模云厂商 CapEx 节奏。2026Q1 强劲增长（净利 105.95 亿）本身就是大客户集中采购的体现，一旦 CapEx 指引下调，季度净利可能快速回落。
  • 风险 3：出口管制升级。美国对华 AI 芯片限制若扩展至更多型号，工业富联中国算力业务将直接承压；此为二元风险，无法对冲。
  • 风险 4：2026Q1 基数效应。2026Q1 净利 105.95 亿，若为一次性集中采购驱动，后续季度可能均值回归至 70-80 亿/季区间，导致 TTM 净利润重回 300-320 亿，PE TTM 将从 32× 反弹至 40-43×，重现估值压力。
  • 风险 5：Tushare 数据局限性。同业 CAGR 样本（5 家）基数均远低于工业富联（最大立讯精密 FY2025 = 166 亿 vs 工业富联 352.86 亿），CAGR 分布无法代表"350 亿基数的代工企业维持 11% 增速"的真实概率分布。本报告仅能用 Tushare 解决"是否有真实数字"，但无法解决"样本适配性"问题。
